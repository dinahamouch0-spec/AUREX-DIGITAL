# عصر صدر الإسلام — موقع تعليمي تفاعلي

موقع عربي (RTL) لعرض مدرسي في مادة اللغة العربية، من 8 أقسام قابلة للتنقل.
لا يحتاج إلى إنترنت ولا إلى أي تثبيت: الخطوط والصور كلها محفوظة داخل المجلد.

## طريقة التشغيل

**الأسهل:** افتح الملف `index.html` بالنقر المزدوج (يُفضَّل Chrome أو Edge).

**أو عبر خادم محلي** (موصى به لربط نافذة المقدّم بالعرض بأكثر الطرق ثباتاً):

```bash
cd sadr-al-islam
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## العرض أمام الصف

| المفتاح | الوظيفة |
|---|---|
| `←` أو `PageDown` | القسم التالي (اتجاه القراءة العربية) |
| `→` أو `PageUp` | القسم السابق |
| `1`–`8` | الانتقال المباشر إلى قسم |
| `Home` / `End` | الغلاف / الخاتمة |
| `F` | ملء الشاشة |
| `N` | لوحة ملاحظات المتحدث |
| `P` | نافذة المقدّم المنفصلة |
| `?` | قائمة الاختصارات |

- **نافذة المقدّم**: اضغط «نافذة المقدّم» (أو `P`)، وضع النافذة الجديدة على شاشة اللابتوب،
  والنافذة الرئيسية على جهاز العرض بوضع ملء الشاشة. تعرض النافذة النص الشفهي، وتنبيهات،
  والقسم التالي، ومؤقتاً، وتتحكم في العرض مباشرة. اسمح بالنوافذ المنبثقة إن طلب المتصفح ذلك.
- أزرار «مُحدِّد التقديم» (Clicker) ترسل غالباً `PageDown`/`PageUp`، وهي مدعومة.
- لكل قسم رابط مباشر: `index.html#s5` مثلاً.

## الملفات

```
index.html        الصفحة الرئيسية (الأقسام الثمانية)
presenter.html    نافذة المقدّم
css/style.css     التصميم
css/fonts.css     تعريف الخطوط المحلية (Amiri, Cairo)
js/app.js         التنقل والتفاعلات
js/notes.js       ملاحظات المتحدث ونصوص الشرح لكل قسم
js/credits.js     مصادر الصور وتراخيصها
img/              الصور (من ويكيميديا كومنز: ملكية عامة أو CC BY-SA)
fonts/            ملفات الخطوط (رخصة SIL OFL)
```

## ملاحظات علمية

- وسوم **«من الكتاب المدرسي»** تميّز إطار الكتاب المدرسي، ووسوم **«إثراء»** تميّز السياق الإضافي.
- الأحاديث موثقة برقمها في صحيح البخاري (6145 و3213)، والآيات من سورة الشعراء (224–227).
- الصور الفنية (لوحات القرن 19م، ومنمنمة الواسطي) رمزية، وتوضح ذلك تعليقاتها.
