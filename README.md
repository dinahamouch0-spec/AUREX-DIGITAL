# Hadi Sport — website

Static site (no build step). Open `index.html` or deploy the folder.

- **Netlify:** Add new site → import this repo → *Base directory* `hadi-sport` (publish `.`).
- **Edit products / contact:** `assets/js/main.js` → `CONFIG` (WhatsApp, Instagram, Google Maps link) and `PRODUCTS`.
- **Product photos:** `assets/img/p/<id>.webp` (800×1000). Swap any file with a real store photo using the same name.
- Bilingual EN / عربي toggle, WhatsApp ordering with size pre-filled, no prices shown.

Stock photos are from Unsplash (free licence); the store photo and logo are Hadi Sport's own.
